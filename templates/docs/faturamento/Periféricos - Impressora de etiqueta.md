## Impressora de etiqueta

Estas impressoras são utilizadas para imprimir etiquetas de preço.

---

### Argox e Zebra

Essas impressoras são específicas para impressão de etiquetas, sendo semelhantes às impressoras não fiscais, com inserção de um rolo de etiquetas.

Estas impressoras possuem um esquema de alinhamento e, sempre que o cliente adquirir uma impressora dessas, é necessário chamar um técnico particular para configurá-la.

> **Dica!!** A retaguarda Shop confeccionou alguns layouts padrões armazenados no seguinte diretório: `G:\SUP\Shop\Ferramentas Úteis\Drives de Impressoras não fiscais`. Antes de abrir atendimento para a retaguarda, confirme se não há o modelo desejado pelo cliente nesta pasta.

---

### Impressora Comum

Se o cliente possui uma impressora comum e quer imprimir etiquetas em papel tamanho A4, é necessário identificar o cenário:

#### O cliente vai imprimir no papel A4 simples e vai cortar depois na tesoura?

Antes de iniciar a criação do layout, verifique com sua supervisão se já existe algum pronto que possa ser utilizado como modelo ou ponto de partida. Assim, você ganhará tempo nessa tarefa.

#### O cliente comprou folhas de etiqueta com tamanhos pré-definidos para destacar da folha?

Para configurar esse tipo de etiqueta, a equipe de retaguarda precisa ter uma folha dessa etiqueta em mãos para poder medir e confeccionar o layout exatamente do tamanho que o cliente comprou.

Explique isso ao cliente e peça para que ele envie uma folha para o endereço:

> **Rua Prefeito Sebastião Teixeira, nº 227 – Centro – Teresópolis RJ – CEP 25953-200**
> Aos cuidados de: Retaguarda Bimer.

Verifique com a sua supervisão qual o prazo pode ser informado ao cliente.

A retaguarda cria o layout, envia o arquivo para o analista que abriu o atendimento, e este liga para o cliente para instalar o layout no sistema.

#### O cliente comprou folhas da PIMACO com tamanhos pré-definidos?

Antes de iniciar a criação do layout, verifique com sua supervisão se já existe algum pronto que possa ser utilizado como modelo ou ponto de partida.

Os nomes das etiquetas começam com **`Etq_Prec_Pimac`** seguidos dos tamanhos.

Nesse caso, o cliente informa o tamanho constante na embalagem da etiqueta, e você busca na pasta se há algum modelo com esse tamanho.

> **Atenção!** Antes de abrir atendimento para a retaguarda, é necessário verificar o modelo da etiqueta e o tamanho. Se possível, peça para o cliente enviar uma foto da etiqueta.
