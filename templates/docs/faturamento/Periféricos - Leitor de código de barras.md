## Leitor de código de barras

O leitor de código de barras é utilizado no comércio de forma geral, como em supermercados, farmácias, lojas de roupas e outros. Quando a empresa adquire um leitor, é necessário realizar algumas configurações que definem o tipo de código de barras que ele fará a leitura.

---

### Configurações do leitor

- **Conexão USB:** se o leitor de código de barras utilizar conexão do tipo USB, não precisa ser configurado no sistema. Basta conectá-lo na máquina.

- **Conexão serial:** se o leitor tiver conexão serial, é necessário configurar no **PDV Alterdata >> Ferramentas Administrativas >> Configurações >> Leitor Serial**, preenchendo os parâmetros para utilização do leitor.

> *[Imagem: tela de configuração do Leitor Serial no PDV Alterdata com os campos de parâmetros]*

> **Importante!!** É necessário configurar quais tipos de códigos de barras poderão ser lidos. Por exemplo: **EAN13**, **EAN9**, entre outros. Essas configurações no leitor serão realizadas pela assistência técnica do cliente.

Além de configurar os tipos de códigos de barras, o técnico da empresa pode configurar para que, ao ler um código de barras, o sistema acione o **Enter** automaticamente, facilitando o processo de lançamento da venda.
