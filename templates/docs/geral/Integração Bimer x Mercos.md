## Introdução

Acho que podemos concordar que algo que a maioria deseja hoje em dia é ter liberdade para fazer suas escolhas. Isso inclui também as empresas. Nenhuma empresa quer ficar limitada ou se sentir obrigada a utilizar uma ferramenta específica. Faz parte do nosso processo de fidelização e retenção, a política de darmos liberdade aos nossos clientes de fazer algumas escolhas de ferramentas (softwares). Imagine a seguinte situação: o cliente precisa de um sistema de força de vendas. A Alterdata possui o aplicativo 4Keep que o cliente poderia adquirir, mas, por necessidades muito específicas, o 4Keep pode não contemplar algo que o cliente precisa. Pode acontecer que, ao insistirmos em colocar nosso aplicativo no cliente, ele acabe ficando insatisfeito ao ponto de querer trocar todo o Bimer por causa disso. Pensando nisso, a Alterdata fechou parceria com a Mercos, empresa conceituada no mercado, que desenvolve softwares e são especializados em automação de força de venda. Seus aplicativos já integram com ERP’s de diversas empresas. E agora também integra com o Bimer. E o 4Keep? Vamos deixar de vendê-lo? Não! O 4Keep continua sendo nossa solução a ser oferecida para nossos clientes. A Mercos só entra na jogada, se por questões particulares, o nosso cliente opte por trabalhar com seus produtos. E ai entramos com a integração Bimer x Mercos.


## Modelo simplificado de integração

A forma de se trabalhar com o Mercos é similar ao que conhecemos no 4Keep. Mas se liga, que similar não quer dizer igual. A integração entre o Bimer e o Mercos ocorre através de uma API disponibilizada pela Mercos. O DSN Bimer criou o IntegradorMercos.exe que exporta dados do Bimer para API Mercos, e importa dados dessa mesma API para o Bimer. O fluxo é bastante simples! 1.O Integrador Mercos faz uma leitura do banco de dados do Bimer, selecionando as informações das tabelas necessárias para a integração; 2.Exporta para a API Mercos, que é a responsável por enviar essas informações para o sistema de força de vendas. Além de exportar os dados do Bimer para a API Mercos, o Integrador também faz a importação, por essa mesma API, das vendas realizadas no sistema de força de vendas, bem como os clientes novos, e cria os pedidos de venda no Bimer. Quando formos explicar as configurações necessárias no integrador, você poderá identificar quais são os dados que serão exportados e importados.


## Integrador Mercos

OIntegradorMercos.exe está disponível, a partir daversão 9.02.01.00, no Instalador Sistemas Gerais (até a versão 10.00.14.00), ou no InstaladorBimerServidor (a partir da versão 11.00.00.00). Ele será salvo junto com os demais executáveis do Bimer no diretório padrão, de acordo com a versão do Bimer do cliente. É legal criar um atalho para o integrador na área de trabalho, para facilitar a vida do usuário. O acesso ao módulo é igual a qualquer outro módulo do Bimer. Ou seja, para que um usuário possa acessá-lo é preciso dar permissão no cadastro de usuário. Lá no cadastro, ou no perfil de usuário, basta incluir o produto“Integrador Bimer x Mercos”. Dica: se for o usuário supervisor, não precisa incluir o módulo. Ao acessar o Integrador, ele será automaticamente minimizado, e ficará disponível na bandeja do Windows. Clique com o botão direito do mouse, para abrir o integrador. Ele é composto de apenas 04 abas, como você pode observar no menu à esquerda da imagem a seguir. Na aba Principal, além da identificação do usuário (1 e 2, você também encontra a legenda do status dos processos de integração. Há também uma lista (3) com os tipos de processos de exportação e importação que o integrador realiza, e quais são as informações integradas, respectivamente. Por exemplo, na primeira linha o Tipo é Exportação e a Referência é Transportadora. Acho que você já deduziu que esse processo exporta os dados da tabela de transportadora do Bimer para a API Mercos. Nas colunas ao lado, o sistema apresenta a Quantidade de transportadoras encontradas no Bimer e o número de registros Integrados, ou seja, quantas transportadoras foram efetivamente exportadas. Observação: a quantidade de produtos encontrados só aparece quando se realiza o processo de integração. Na tela principal há outras funções e informações importantes sobre a integração, porém, antes de falar sobre elas é preciso configurar o integrador para que ele consiga fazer os processamentos. Para isso, clique na opçãoConfigurações no menu à esquerda. 1.Ambiente – A Mercos disponibiliza 02 ambientes para o cliente: um de Homologação, no qual ele pode realizar seus testes; e outro de Produção, que é o que a empresa trabalhará para valer, fazendo vendas e movimentações reais. Mas fique atento porque há um detalhe muito importante a esse respeito. Se for trabalhar com ambiente de homologação, tem de criar uma base no Bimer específica para isso. Nunca faça os testes na base de dados oficial do Bimer, porque nela serão criados registros que depois vão dar dor de cabeça para o cliente, e por consequência para o suporte. 2.Company Token – A API Mercos possui um mecanismo de autenticação que impede que outros usuários tenham acesso e façam qualquer tipo de alteração nas informações da empresa. Este mecanismo de autenticação é baseado em tokens. Os tokens são parecidos com uma senha de acesso, mas com a vantagem de serem únicos dentro do sistema. Eles são gerados automaticamente e nunca são repetidos, garantindo que o cliente possua um token exclusivo que o identifica. Para fazer qualquer operação na API, é necessário informar o Company Token, que identifica a empresa. Nós não temos acesso a esse token, mas nosso cliente pode obtê-lo na plataforma Mercos (ainda veremos como acessar). Ele terá de fazer login com usuário fornecido pela Mercos e clicar em Minha Conta / Sistema. Nessa área estará disponível o seu Company. Token. Atenção: Assim como existem 02 ambientes de trabalho, o de homologação e o de produção, também existem o Company Token de homologação e o Company Token de Produção. Eles devem ser informados corretamente, de acordo com o tipo de ambiente marcado na opção anterior. 3.Empresa – Essa informação é bem tranquila. Basta informar o código da empresa no Bimer que será usada para integração. Por exemplo, a empresa informada nesse campo será considerada para identificação dos produtos e saldos a serem exportados para a API Mercos, bem como é para ela que serão criados os pedidos de venda importados da API Mercos. Observação: o integrador trabalha com relação de um para um, o que inviabiliza o uso de mais de uma empresa na integração. Essa condição se dá pelo fato de a Mercos não ser uma plataforma multiEmpresa e, caso o cliente use mais de uma empresa para venda, a Mercos cria um ambiente (base de dados) para cada, o que gera para cada empresa um "Company Token" diferente, impossibilitando que coloquemos ambos os códigos no integrador e possamos selecionar mais de uma empresa para relação. Para implementar uma solução é necessário modificar toda a interface de configuração que conhecemos no integrador, pois precisaríamos de uma tela de configuração específica por empresa, conforme já alinhado com o DSN. No momento, não há previsão para que essa alteração seja realizada. 4.Setor de saldo de produtos – Algumas empresas disponibilizam o saldo dos seus produtos para o sistema de força de vendas. Assim os vendedores têm uma “limitação” para vender. Só podem vender a quantidade disponível em estoque. Se for esse o caso do cliente que você estiver atendendo, e a empresa fizer controle de estoque por setor, é necessário informar qual o setor principal de estoque. O setor informado nesse campo também será utilizado comosetor de movimentação do produto, informado como setor de saída no pedido de vendas importado. Antes de passar para o próximo campo, temos ainda duas informações importantes a respeito do setor/saldo de estoque enviados para a API: 4.1. Se a empresa trabalhar com mais de um setor de estoque de produtos, para fazer suas vendas, será necessário ajustar manualmente o setor de saída do produto no pedido de vendas, após ele ser importado. 4.2. Os saldos dos produtos só serão enviados se nas configurações do sistema da Mercos estiver marcado para Controlar Estoque. Se o nosso cliente quiser configurar isso, ele deve acessar o site da Mercos, clicar na área Produtos e selecionar a opção “Gerenciar Estoque”. Na primeira vez que entrar nessa opção, o sistema da Mercos informará que o Controle de Estoque está desabilitado, e se ele deseja habilitar. Observação: A empresa não é obrigada a trabalhar com controle de estoque no Mercos. Então, se esse controle não estiver configurado, o integrador avisará durante o processo de exportação, que não enviará os saldos de produtos, porque a empresa não trabalha com Controle de Estoque no Mercos. Dica: é muito importante que você oriente o nosso cliente que ele mantenha contato o suporte da Mercos para saber mais detalhes sobre o controle de estoque e suas consequências. 5.Operação para importação do pedido de vendas – Quando o integrador faz a importação das vendas realizadas no sistema Mercos, ele criará um pedido de vendas no Pedido de venda, e para isso ele precisa saber qual a operação deve ser utilizada. 5.1. Para a operação do Bimer aparecer nessa tela precisa está configurada com o tipo de movimento de Venda, e se for necessário gerar títulos a receber, marcar Atualizar financeiro. 5.2. Mas e se a empresa trabalhar com mais de uma operação de venda? Por enquanto, será necessário trocar a operação no próprio pedido de vendas, depois que ele for importado. 5.3. Outra opção que o Integrador Mercos ainda não está fazendo, é quando no cadastro do cliente é informada a sua operação padrão para vendas. Os pedidos de venda são criados sempre com a operação informada no integrador. 6.Cálculo de ICMS – Serão exportados para a API Mercos os dados do ICMS, por produto, de acordo com a tabela informada nesse campo. O sistema da Mercos usará essas informações para criar as regras de cálculo na vendas. Parece meio óbvio, mas é preciso lembrar que a tabela informada nesse campo tem de estar também no cadastro dos produtos. Se não, você terá problemas na hora da integração. 7.Característica dos produtos integrados – Muitas empresas possuem produtos em seu cadastro que não são itens de venda, como material de uso e consumo, matéria-prima, etc. Por isso, é possível indicar qual característica de produto deve ser considerada para exportação dos produtos. Se nenhuma característica for informada, todos os produtos serão exportados. O integrador não faz distinção do tipo do produto, apenas pela característica de produto. 8.Característica dos clientes integrados – Algumas empresas selecionam quais clientes, que já existem na base de dados do Bimer, devem ser enviados para o sistema da Mercos. Nesse caso, deve-se criar uma característica de pessoa para identificar esses clientes, e informá-la nesse campo nas configurações do Integrador. Se não for informada, todos os clientes serão exportados. 9.Equivalência para categoria de produto no Mercos – É possível escolher qual tabela do cadastro de produtos será considerada como Categoria no sistema Mercos. Se será o Grupo ou a Família do produto. Se não for trabalhar com Categoria no Mercos, é só marcar a opção “Nenhuma”. Mas, o que é essa tal “Categoria” no sistema Mercos? Dê uma olhada na imagem a seguir deste marketplace. A categoria é a separação do produto por similaridade dentro um e-commerce. Como só é possível enviar um tipo de categoria, então é necessário escolher se corresponderá ao Grupo ou à Família do produto. 10.Trazer o representante principal para o repasse do pedido – Marcando essa opção, ao importar e criar um pedido de venda, o representante marcado com como principal no cadastro do cliente no Bimer, será utilizado como pessoa de repasse, independente de quem fez a venda.

11. Recalcular o ICMS-ST na importação do pedido –Marque caso seja
necessário recalcular o valor de ICMS ST na importação do pedido para o Bimer. Mesmo que o usuário tenha lançado esse tributo na Mercos com uma alíquota X, dentro do módulo Pedido de venda, será respeitado o que está configurado no Bimer. 12.Exportar o código EAN no campo Informações Adicionais – Caso o código principal do produto seja o código EAN, o código será levado no campo de Informações Adicionais no cadastro do produto na plataforma Mercos. 13.O desconto/acréscimo será aplicado sobre o valor unitário:Com essa opção, ao integrar o pedido para o Bimer, o valor unitário do item será o valor líquido do Mercos. 13.1.Vamos a um exemplo: 13.1.1. Características que serão utilizadas como tags de clientes – Escolha quais características de pessoas serão levadas para a Mercos como marcadores, categorias ou simplesmente adjetivos de clientes. O vínculo de características de clientes do Bimer não é feito automaticamente, é necessário acessar o cadastro de clientes da Mercos / Vínculos e Permissões / Selecionar os clientes / Editar vínculos e permissões / Escolher as Tags (características) / Adicionar ou Substituir. 15.1.Este campo pode ser usado na plataforma para pesquisar um grupo de clientes que possua a mesma Tag, como exemplo: É necessário localizar todos os clientes que a empresa adquiriu no último semestre (Característica de Maternidade) 16.Operação para importação dos pedidos de saída – Ao criar um pedido na Mercos, o usuário pode classificar com o tipo de saída, desse modo, ao integrar o pedido será criado com esta operação. 16.1.O pedido de saída na Mercos, é integrado e faturado normalmente no Bimer, a diferença é que na plataforma Mercos o pedido de saída é desconsiderado de alguns relatórios e consultas. 16.2.Para a operação do Bimer aparecer nessa tela precisa está configurada com o tipo de movimento de Saída, e se for necessário gerar títulos a receber, marcar Atualizar financeiro.

## Processo de integração

Agora que já configurou o integrador, ele já está pronto para o uso, seria só minimizar e aguardar o intervalo de tempo programado nas configurações do agendamento. Mas não precisa ficar esperando esse tempo todo para vê-lo funcionamento. Você pode adiantar o processo, na tela principal do Integrador Mercos. Nós já vimos algumas informações sobre ela, mas detalharemos um pouco mais as funções existentes nela. A opção Executar Integração disponível no topo da tela faz uma sincronização completa das informações listadas nela. Ou seja, serão exportados todos os dados necessários do Bimer para a API Mercos, e são importadas as vendas e clientes da API Mercos para o Bimer. Essa opção tem a mesma função do processo que é feito a cada intervalo de tempo agendado nas configurações do Integrador. Há também a opção Parar Integração, caso seja necessário fazer alguma interrupção no meio do processo. Durante o processo de atualização o Integrador mostra nacoluna Progresso o andamento da integração de cada tipo de informação, e também o resultado, de acordo com a legenda de cores que fica logo acima. • Executando (Amarelo) - A integração daquela tabela específica está em sendo realizada naquele momento. • Sucesso (verde) – Indica que 100% do processo de integração daquela tabela foi realizado, e não ocorreu nenhum erro durante ele. • Alerta (vermelho) – Fique atento porque aconteceu algum problema durante o processo de integração. Os motivos podem ser diversos, como falta de conexão com a API Mercos, inconsistência nos dados, entre outros. Na área de Log (vamos falar sobre ela nos próximos tópicos), é possível identificar o(s) motivo(s) do problema na integração. No exemplo da imagem acima, podemos observar que para quase todas as tabelas a integração ocorreu com sucesso (verde), e apenas na opção de exportação de clientes teve erro (vermelho). Observe que na linha Clientes, na coluna Quantidade há a informação de que foram encontrados 3 registros na base de dados do Bimer, mas na coluna Integrado está igual a zero, indicando que nenhum cliente foi exportado. Não sei se você também reparou que não são em todas as tabelas que há informações nas colunas “Quantidade” e “Integrado”, e mesmo assim a legenda indica sucesso no processo. Isso pode acontecer por 02 motivos: 1.Realmente não existe nenhuma informação na referida tabela na base de dados do Bimer. O que podemos combinar que não é muito comum de ocorrer, visto que essas informações são necessárias para as vendas no sistema Mercos. 2.A integração da referida tabela já ter sido totalmente exportada ou importada (dependendo do tipo de tabela) em processos anteriores, e não há nenhuma informação nova a ser integrada. Isso ocorre porque oIntegrador Mercos faz um processo incremental de sincronização de dados. Ou seja, na primeira vez que a integração é executada, 100% da informação é exportada ou importada. Nos processos seguintes somente serão integrados os dados novos ou alterados na tabela. Tem algo muito legal que temos de te contar! Devido ao processo de Integração Incremental que citamos, e o sistema só pegar os dados que ainda não foram integrados, no exemplo acima, em que ocorreu erro na integração da tabela de clientes, no próximo processamento (se não houver nenhuma informação nova nas outras tabelas) o Integrador tentará integrar novamente só a tabela de clientes. Mas não terminaram as formas que temos para realizar a integração de uma tabela não. Uma você já deve até ter notado. Ao lado da coluna Progresso de cada tabela há a opção Integrar. Ela pode ser usada quando você quiser processar a integração de uma tabela específica. Ainda usando o exemplo do erro na tabela de clientes, imagine que o problema foi detectado e corrigido. Você não vai querer gastar seu tempo e do nosso cliente colocando para processar todas as tabelas de novo. Então, é só clicar em Integrar no final da linha. O bom é que ele continua de onde parou. Por exemplo, a empresa tem 4.500 produtos em sua base, o integrador conseguiu enviar 4.200, e 300 deram erro. Após corrigir, clicando em integrar, serão processados só os 300 que faltaram. E a terceira opção de integração, já que falei que havia mais 02? Basta clicar com o botão direito sobre a tabela desejada, que aparecerá a opção “Forçar a integração total das tabelas XXXXXX”. Mas calma aí! Não vá clicando assim do nada! Você leu direitinho a descrição da opção? Forçarreintegração total. Ou seja, clicando nela toda a tabela será reprocessada e não somente as informações novas ou que faltaram no processo anterior. Então só use essa opção se for isso mesmo que deseja, que o integrador processe novamente toda aquela tabela. Como foram muitas informações sobre o processo de integração, que tal fazer um resumo? Resumindo: O processo de Integração é incremental, ou seja, somente os dados que ainda não integrados é que são processados. E há as seguintes formas de realizar a integração: • Automaticamente através do agendamento configurado no Integrador; • Manualmente através da opção “Executar integração” na aba principal do integrador; • Manualmente através da opção “Integrar” ao lado de cada tabela; • Manualmente através da opção“Forçar a integração total das tabelas XXXXXX” clicando com o botão direito do mouse sobre a tabela desejada. Nesse caso a integração não será incremental. Todo o processo será refeito.


## Log de integração

Você já sabe que quando falamos em integração, principalmente entres sistemas de empresas diferentes, podem ocorrer algumas inconsistências que impeçam a exportação e importação. É um campo que a empresa mudou de nome ou de tipo… é uma API que está fora ar… É uma informação que está sendo enviada que o outro sistema não reconhece. Ou seja, podem acontecer diversos imprevistos no meio do caminho. Na aba principal, você viu que quando há alguma inconsistência na integração, o Integrador sinalizará através do status do progresso da tarefa. Quando o Status for de alerta será criado um Log com o motivo da inconsistência. No exemplo acima, podemos ver 02 ocorrências • 27/08/20XX 09:43:51 Categoria (TECIDO)(nome) Não é possível criar uma categoria que tenha o mesmo nome de outra categoria com mesmo pai. • 27/08/20XX 09:43:51 Categoria (LINHA BRANCA) (nome) Não é possível criar uma categoria que tenha o mesmo nome de outra categoria com mesmo pai. A tabela Categoria no Mercos corresponde a tabela de Grupos ou de Família no Bimer. Nesse exemplo, o integrador estava configurado para considerar Grupos como categoria. Então podemos entender, pelas mensagens acima, que as categorias Tecido e Linha Branca não foram enviadas porque há mais de um grupo com o mesmo nome. Note na imagem acima que realmente existem grupos com o mesmo nome. Dica: Quando o integrador encontra alguma inconsistência, além de demonstrar na tela de Log, ele também salva esse log no arquivo IntegradorMercos.xml no mesmo diretório onde se encontra o executável. Além, disso você também pode usar as teclas de atalho <Ctrl + A> para selecionar todas as mensagens, e copiar com <Ctrl + C>. Assim, você poderá salvar esse conteúdo em um doc ou Excel se preferir.


## Detalhes importantes sobre a integração


### Dados exportados

• Transportadoras – São exportadas todas as transportadoras que existem no Bimer. E somente o telefone marcado com principal no cadastro será enviado. Se uma transportadora já tiver sido integrada, e for excluída no Bimer, ela não será excluída automaticamente no Mercos. O usuário terá de excluir manualmente no Mercos. Se uma transportadora for cadastrada no próprio sistema da Mercos, ela não será importada para o Bimer. • Formas de pagamento – Somente são exportadas formas de pagamento ativas no Bimer. Quando uma forma de pagamento for exportada e cadastrada no Mercos, ela não poderá mais ser excluída ou inativada no Bimer. Para minimizar o impacto, o Integrador Mercos, ao detectar que no cadastro de produtos no Bimer há configurações para venda por embalagem, a quantidade por embalagem será enviada como complemento da descrição, e o vendedor terá de fazer a multiplicação. Exemplo: No Bimer, a Caneta esferográfica azul é controlada por unidade, mas nas opções do produto está configurada a venda por embalagens, com 50 unidades em cada caixa. ## Tributação

Neste momento, vim aqui te esclarecer algumas coisas sobre tributação no momento da integração: 1 O usuário do Mercos pode lançar o pedido com qualquer tributação no produto, mesmo que seja diferente das configurações no Bimer. Na integração serão preservados os dados do pedido cadastrado no Mercos. 1.1 Ex.: No Bimer o IPI do produto está com 5%, mas o cliente lançou o pedido com 3%, na integração aparecerá 3%. 2 Ao marcar a opção Recalcular ICMS ST na Importação do pedidono Integrador Mercos, o pedido de vendas no Bimer será recalculado em relação ao que foi lançado na Mercos. 2.1 Por enquanto apenas o ICMS ST tem essa possibilidade, todos os outros tributos preserva o que foi lançado na Mercos. 3 FCP e FECP: No sistema Mercos não é possível calcular esses tributos. Se você atender um cliente que precisa disso, ajude-o a configurar no Bimer do modo como você já está acostumado. E desse modo, esses tributos serão calculados apenas com base na Importação do pedido. 4 NaExportaçãoalguns dados do Bimer são levados para a Mercos para facilitar a vida do usuário. Veja quais são: 4.1 Na plataforma Mercos / Produtos / Configurações / Tributações são adicionados os NCMs do Bimer (cadastros no Configurador / Estoque / Tributos / Classificação Fiscal).Veja abaixo como cada campo foi obtido: 4.1.1 Margem de Valor Agregado: O percentual é obtido da aba Substituição Tributária / Antecipação de ICMS ST do cálculo de ICMS presente no Integrador Mercos. A MVA da classificação não é usada na Integração. 4.1.2 Alíquota destino: Obtida primeiro da Classificação Fiscal / Aba ICMS / Al. Interna de ICMS. Se não estiver preenchida, será verificada a UF de destino da venda (Configurador / Geral / Endereço / UF). 4.1.2.1 Essa alíquota será usada no cálculo de ICMS ST. 4.1.3 Alíquota Crédito: O percentual é obtido da aba Dados, campo Alíquota de ICMS do cálculo de ICMS presente no Integrador Mercos. 4.1.3.1 Essa alíquota será usada no cálculo de ICMS próprio (comum). Se liga!Como já vimos, o IPI é apresentado no produto a partir da tabela de classificação fiscal do Bimer.


## Padrões de Atendimento

Registrar os atendimentos no CRM: O padrão para estruturar o parecer e gerar retorno não mudam. Na maioria dos casos você usará o tipo de atendimento: 000142 - Dúvidas/Problema de Integração, pois não temos um tipo específico para Mercos. O Produto a ser utilizado é o Integrador Mercos. Limite no atendimento: Se o cliente entrou em contato informando que o valor de comissão e tributo está calculando errado na plataforma, como base de cálculo errada de ICMS, informe ao cliente que ele deve contatar o suporte da empresa Mercos. No caso da tributação, só faça algum ajuste se for algo no Bimer, como exemplo: Alíquota de MVA está incorreta pois lá no Bimer o cliente informou assim. Isso traz a atenção para não mexermos em coisas que não são da integração. Ambiente de Testes: Se precisar testar algo internamente contate sua supervisão. Hoje não temos como criar ambientes de testes para cada colaborador(a).
